# Constructor Events

Страница-конструктор события «Ночь в музее»: показывает данные мероприятия, позволяет выбрать дополнительные услуги и считает итоговый отчёт.

## Как открыть

Откройте файл `src/index.html` двойным кликом в браузере — сервер не нужен.

## Структура

```
src/
  index.html  — разметка страницы
  style.css   — стили
  app.js      — логика: разбор JSON, расчёт отчёта, обработчики
```

## Что делает страница

1. Разбирает `sourceJson` через `JSON.parse`.
2. При успехе показывает карточку события и форму выбора услуг.
3. При ошибке парсинга показывает блок `#data-error` («Ошибка данных.»).
4. По кнопке «Показать программу» открывает время сбора и начала.
5. По отправке формы считает отчёт функцией `buildReport` (`filter` / `map` / `reduce`).
6. Выводит итог: количество услуг, сумму и названия; ниже — JSON-строку отчёта.
7. Если ничего не выбрано — показывает «Выберите хотя бы одну услугу.»
